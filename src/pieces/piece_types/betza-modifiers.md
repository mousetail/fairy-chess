## Atoms (capital letters — define the basic move/step)

The tables are generated by Claude based on https://www.gnu.org/software/xboard/Betza.html.

Note: Neither our own parser nor Stockfish supports all combinations of atoms and modifiers. Stockfish has the nasty habbit
of ignoring invalid modifiers leading to bad engine performance.

| Atom | Meaning |
|---|---|
| **W** | Wazir — 1 step orthogonal (1,0) |
| **F** | Ferz — 1 step diagonal (1,1) |
| **D** | Dabbaba — (2,0) leaper |
| **N** | Knight — (2,1) leaper |
| **A** | Alfil — (2,2) leaper |
| **C** | Camel — (3,1) leaper (older notation: J) |
| **Z** | Zebra — (3,2) leaper (older notation: L) |
| **H** | (3,0) leaper (Threeleaper) |
| **G** | (3,3) leaper |
| **B** | Bishop = shorthand for F0 (unlimited diagonal slide) |
| **R** | Rook = shorthand for W0 (unlimited orthogonal slide) |
| **Q** | Queen = shorthand for F0W0 (= BR) |
| **K** | King = shorthand for FW (1 step any direction) |
| **O** | "oh" — null move (stand pat, not implemented in 4.8.0); also reused as the castling atom, where a following number gives how many steps the king-like piece takes toward the corner |
| **U** | Universal leaper — can jump to any square on the board (not implemented in 4.8.0) |
| **@** | Drop atom — piece can be dropped from hand (not implemented in 4.8.0; parsing stops here) |

A number after an atom sets its **range** (max repeats of that step); `0` = unlimited. E.g. `N0` = Nightrider, `A0` = unlimited Alfil-slider.

## Modifiers (lowercase — placed before an atom, in this required order: i, directional, m, c, d, e, t, p, g, o, y, n, j)

### Directional

| Modifier | Category | Meaning |
|---|---|---|
| **f** | Directional | Forward |
| **b** | Directional | Backward |
| **r** | Directional | Right |
| **l** | Directional | Left |
| **v** | Directional | Vertical (f + b) |
| **s** | Directional | Sideways (l + r) |
| **h** | Directional | "Half" — expands a direction to all 4 moves with a component that way (oblique atoms only) |
| **hl / hr** | Directional | Left-handed / right-handed move set of a chiral (oblique) atom |

### Modality

| Modifier | Category | Meaning |
|---|---|---|
| **m** | Modality | Non-capture (quiet move) only |
| **c** | Modality | Capture only |
| **e** | Modality | Allows en passant capture |

### Jumping

| Modifier | Category | Meaning |
|---|---|---|
| **n** | Jumping | Non-jumping — blocked by an occupied intermediate square |
| **j** | Jumping | "Must jump" the intermediate square; on a 1-step slider (W/F) it instead means "skip the first square" |
| **jj** | Jumping | Can jump over multiple intermediate squares (vs. `j` = exactly one) |
| **p** | Hopping | Must hop exactly one obstacle (the "platform"), sliding on after it — e.g. the Cannon |
| **g** | Hopping | Like `p`, but can only move exactly one square past the platform — e.g. the Grasshopper |
| **t** | Special | With `g`/`p`: platform can't be an enemy piece. On the final leg alone: piece can't capture kings (used to mark "imaginary" moves as non-checking) |

### Multi-leg

| Modifier | Category | Meaning |
|---|---|---|
| **q** | Special | Curved-path rider (not implemented in 4.8.0) |
| **z** | Special | Zigzag-path rider (not implemented in 4.8.0) |
| **o** | Special | Move wraps around a cylindrical board |
| **a** | Multi-leg | "Again" — piece may make another leg after completing this one; what follows describes the next leg |
| **y** | Multi-leg | Range-changing version of `m` (mirrors what `g` does to `p`) — bends path on an *empty* square |

### Other

| Modifier | Category | Meaning |
|---|---|---|
| **i** | XBetza | Only legal for a "virgin" (never-moved) piece |
| **d** | (listed in ordering rule only; not otherwise defined in this text) |

### Special case: modifiers on `@` (drops)
Since directions don't apply to a drop, these letters are repurposed:

| Modifier on @ | Meaning |
|---|---|
| **f** | Can't drop on a file that already has this piece type |
| **s** | Can't drop on a square of the same color as an existing piece of this type |
| **b** | Can't drop if this piece type exists anywhere on the board |
| (doubled, e.g. **ff**) | Raises the cap from one existing piece to two |
| **j** prefix on `@N` | Exempts the back rank from the drop zone |
| number after `@` | Depth of the legal drop zone in ranks, counted from the back rank (default 1) |
